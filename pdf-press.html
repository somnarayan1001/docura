PDF Press

PDF and image tools that run right in your browser.

Files never leave your device
Drop PDFs to merge

Add two or more files, then drag them into the order you want.

    Drop a PDF to split

    Pull out page ranges or break the document into equal parts.

      How to split

      Separate with commas. 4- means page 4 to the end.
      Drop PDFs to compress

      Works best on scanned documents and image-heavy files.

        Compression level

        Each page is saved as an image, so text can no longer be selected or searched. If a file would get bigger, the original is kept.
        Drop images to compress

        JPG, PNG, WebP, GIF, BMP, TIFF, HEIC and AVIF. Mix formats freely.

          Compression settings

          70
          70 is a good balance. Lower means smaller files.
          Smaller images are never enlarged.
          Drop images to convert

          Each file's format is detected automatically, so you can mix JPG, PNG, WebP, HEIC and more.

            Everything runs on your device using pdf-lib, PDF.js and your browser's own image tools. Nothing is uploaded.
