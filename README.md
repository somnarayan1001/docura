# PDF Press

Merge, split and compress PDFs in your browser. Files are processed on your device and never uploaded.

**Use it:** https://somnarayan1001.github.io/pdf-press/

- **Merge** – combine several PDFs and drag them into order
- **Split** – custom page ranges (e.g. `1-2, 3, 4-`) or a new file every N pages, download as a .zip
- **Compress** – Less, Medium (recommended) or High compression

Built with [pdf-lib](https://pdf-lib.js.org/), [PDF.js](https://mozilla.github.io/pdf.js/) and [JSZip](https://stuk.github.io/jszip/).
